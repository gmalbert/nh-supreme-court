# Integration Guide: Add Data Status Widget to All Pages

## Overview

This guide explains how to add the `render_data_status()` widget to all pages in the Granite State Appeals app. This widget displays:
- Last data update timestamp
- GitHub Actions workflow status
- Link to NH Supreme Court opinions page

## What You Need to Do

Add the data status widget to **9 page files** by:
1. Importing the function at the top of each file
2. Calling the function after the page title

---

## Files to Update

### 1. **pages/01_Opinions.py**

**Add at top of file** (after existing imports):
```python
from utils.site_chrome import render_data_status
```

**Add after the title** (around line 20-30, after `st.title()` or `st.header()`):
```python
render_data_status()
```

**Example placement:**
```python
st.title("📜 Opinions")
render_data_status()  # Add this line
st.markdown("Search and explore NH Supreme Court opinions")
```

## What the Widget Displays

The `render_data_status()` function shows:

```
📊 Data last updated: January 15, 2026 at 11:05 AM UTC

View latest workflow run | New Hampshire Supreme Court Opinions
```

- **Timestamp**: From `data/processed/refresh_manifest.json` (generated by GitHub Actions)
- **Workflow link**: Links to the most recent GitHub Actions run
- **Court link**: External link to the NH Supreme Court opinions page

## Troubleshooting

### Widget doesn't appear
- Check that you added the import at the top of the file
- Ensure you called `render_data_status()` after the title
- Verify the file is saved

### Import error
```
ModuleNotFoundError: No module named 'utils.site_chrome'
```
**Solution:** Make sure you're running from the project root directory and that `utils/site_chrome.py` exists.

### No data displayed
- The widget will show "Data last updated: Unknown" if `data/processed/refresh_manifest.json` doesn't exist
- This is expected before the first GitHub Actions run
- You can manually create the file for testing:
  ```json
  {
    "timestamp": "2026-01-15T11:05:00Z",
    "run_id": "12345678",
    "run_url": "https://github.com/your-org/nh-supreme-court/actions/runs/12345678"
  }
  ```

## Automation Tip

You can use a script to add the import to all files at once:

```bash
# Add import to all page files
for file in pages/*.py; do
    if ! grep -q "from utils.site_chrome import render_data_status" "$file"; then
        # Insert after the first import block
        sed -i '' '/^import /a\
from utils.site_chrome import render_data_status
' "$file"
    fi
done
```

**Note:** This only adds the import. You'll still need to manually add the `render_data_status()` call in the appropriate location for each page (after the title).

## Questions?

If you encounter issues:
1. Check that `utils/site_chrome.py` exists and has the `render_data_status()` function
2. Verify you're using Python 3.9+ and have all dependencies installed
3. Look for error messages in the Streamlit terminal output
4. Test with a single page first before updating all pages

Once all pages are updated, the data status widget will provide consistent, up-to-date information about data freshness across the entire application.
