House 2002 Block Equivalency File (.dbf)
Block Equivalency File -- This is a file from the United States Department of Justice that defines the census
blocks for each House district in New Hampshire as a dBase file. This dBase file contains three fields of data:
the block numbers for each census block; the assigned House District in character form for each census block;
and the assigned House District in numeric format for each census block.

Arcview GIS Shape File (.shp)
Arcview GIS Shape File (.dbf)
Arcview GIS Shape File -- File for importing the House Districts into Arcview GIS software, a desktop
mapping program from ESRI, Inc. A free GIS data viewer called ArcExplorer is available for download from
ESRI's website. This free GIS data viewer can be used to view the Arcview Shape File posted on this website.
You will need to download all the Arcview files into a single directory on your PC for viewing with Arcview or
ArcExplorer software.
